# Research Report Audit

Audits research and investment conclusions for stale sources, cherry-picking, mechanism mismatch, and conclusion overreach.

## Use

1. Copy `templates/input.md`.
2. Paste the memo claim, source dates, raw artifacts, method, and falsifier.
3. Apply `SKILL.md` as the workflow contract.
4. Return JSON matching the verdict schema.

This workflow signs off evidence discipline; it is not a memo-writing prompt.
