# AI PR Review

Reviews PR and migration safety claims against raw diff, tests, CI, runtime evidence, and permission boundaries.

## Use

1. Copy `templates/input.md`.
2. Paste the claim, diff summary, commands, raw outputs, and runtime evidence.
3. Apply `SKILL.md` as the workflow contract.
4. Return JSON matching the verdict schema.

This is a sign-off workflow, not a generic code review prompt.
