LIVE EXECUTOR · DERIVED FRESHNESS

Today's signal, weeks-old inputs

APPARENT GREEN
Cron OK, today's signal timestamp, executor verify PASS.
REAL FAILURE
Underlying panel CSVs had stopped updating weeks earlier.
FALSIFY REQUIRED
Refresh and coverage gates, provenance manifest, and a permanent incident replay through the production wrapper.

02

QUANT RESEARCH · EVIDENCE INTEGRITY

A strict PASS overturned by hidden input assumptions

APPARENT GREEN
Saved returns passed DSR, PBO, and permutation checks.
REAL FAILURE
Coverage, row loss, and an implicit missing-data policy had already shaped the evidence surface.
FALSIFY REQUIRED
Calendar contract, row-loss audit, coverage manifest, and missing-policy variants before metric gates.
Inspect repository context ↗
03

RUNTIME · MIRROR DRIFT

The mirror was fixed. The runtime was not.

APPARENT GREEN
The vault mirror contained the v0.6.8 return-basis fix.
REAL FAILURE
The actual second-profile runtime still executed the old version.
FALSIFY REQUIRED
Read and test the real runtime path, then verify runtime and mirror together.

HOW IT WORKS

Three layers. One plain question: where is the evidence?

Adversarial red-teams "looks fine." Framework catches what will rot later. Cutline says Must Fix / Debt / Delete. Then PASS, PASS_WITH_DEBT, or BLOCK.

  1. 01

    Claim

    Something asserts success — a deploy, a metric, a “done” without proof.

  2. →
  3. 02

    Adversarial

    Red-teams what looks fine — AI hallucination, false-green, and confident claims without evidence.

  4. →
  5. 03

    Framework

    Catches what will rot later — hidden state, duplicated authority, brittle rollback, over-engineering.

  6. →
  7. 04

    Cutline

    Must Fix / Known Debt / Delete — what to change, what to record, what to remove.

  8. →
  9. 05
