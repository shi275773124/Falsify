# Falsify Homepage Benchmark Notes

## Poolmoney learnings

Poolmoney makes the product feel real by showing concrete product objects instead of explaining abstract positioning. The account, pools, collaborators, roles, cards, balances, and use cases make the homepage feel usable before the visitor reads much copy.

Falsify should learn:
- Lead with product objects: claim, attack path, cutline, verdict, raw artifact.
- Use practical use cases to make the product world believable.
- Keep explanations short and let objects carry meaning.
- Make the page lighter and more usable than a dark concept poster.

## Consensys learnings

Consensys uses a world thesis first, then deepens into stack storytelling. The page feels coherent because product, protocol, ecosystem, and CTA all belong to one category-level idea.

Falsify should learn:
- Start with a world thesis: AI conclusions need a place to be attacked before trust.
- Show a simple loop first, then the deeper adversarial sign-off stack.
- Make every section feel like another layer of the same system.
- Use repeated vocabulary: Submit, Attack, Cutline, Verdict, Artifact, BLOCK.

## AI Visual Prompt Cookbook learnings

The cookbook is useful because it treats visuals as reusable systems, not one-off images. Each style has a repeatable grammar, examples, and source prompt logic.

Falsify should learn:
- Define a visual system before producing assets.
- Reuse the same object language across hero, loop, use cases, case study, and archive.
- Keep state colors and typography roles consistent.
- Avoid creating one impressive hero that later sections cannot share.

## What not to copy

Do not copy Poolmoney's consumer-fintech tone, emoji-heavy use cases, or exact layout.

Do not copy Consensys colors, crypto-world imagery, or exact stack structure.

Do not copy the cookbook's poster/collage styles. The relevant lesson is reusable prompt-system discipline, not visual loudness.

## Current Falsify implication

The homepage should become a bilingual product-world homepage: a sign-off workspace, review room, use-case library, Sharpe proof dossier, and raw artifact archive. BLOCK remains important, but it must not be the only object carrying the page.
