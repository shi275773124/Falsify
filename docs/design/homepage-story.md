# Falsify Homepage Story

## Thesis

AI conclusions need a place to be attacked before they are trusted.

Falsify is the adversarial sign-off workspace for high-risk AI conclusions.

## Page narrative

1. Hero / Product world thesis
   - Headline: One AI review isn't enough.
   - Show a review room with claim, attack path, cutline, verdict, and raw artifact.
   - BLOCK appears as a decisive verdict, not as the only visual asset.

2. Product loop
   - Submit
   - Attack
   - Cutline
   - Verdict
   - Artifact
   - This is the simple product mental model.

3. Sign-off stack
   - Conclusion Intake
   - Framework Review
   - Adversarial Review
   - Cutline
   - Verdict
   - Raw Artifact
   - This is the deeper protocol beneath the simple loop.

4. Use-case world
   - Quant strategy
   - Investment memo
   - Legal memo
   - Research report
   - AI agent action
   - Launch plan
   - Customer-facing analysis
   - Security review
   - Each tile shows claim, attack, and possible verdict.

5. Sharpe 4 case
   - Sharpe 4.06.
   - 6/7 gates passed.
   - Still BLOCKED.
   - Founder portrait and original field note are preserved as origin evidence.

6. Raw artifact archive
   - Make artifact records inspectable.
   - Show artifact ID, verdict, findings, cutline, minimal action, reviewer metadata, and reproduce command.

7. Product reality
   - CLI
   - JSON artifact
   - Verdict schema
   - GitHub Action
   - Sample report
   - Do not overclaim.

8. Final CTA
   - Run sample review
   - Install GitHub Action
   - View raw artifact

## Tone

High stakes, but usable. Premium evidence workspace, not compliance PDF. Product language should be direct and concrete.

## Failure modes to avoid

- Dark concept poster
- One BLOCK report doing all the work
- Dashboard
- Terminal hacker page
- Mixed-language page
- Disconnected section styles
- Generic AI SaaS blocks
